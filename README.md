# TypeTap

A minimal Monkeytype-inspired typing site with the TypeTap palette:
- Electric Cyan `#4BE3FF`
- Deep Navy `#0B1A2E`
- Soft Gray `#D9E1E8`
- Punch Red `#FF4A4A`
- JetBrains Mono

Features: 15/30/60 second tests, live WPM/accuracy, saved local rankings, stats, responsive UI, and a 5,000-word pool.

Run locally with a static server, for example `python -m http.server 8000`, then open `http://localhost:8000`.
